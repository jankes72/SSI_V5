# SSI V5 — Current Research Roadmap — 2026-09-30

**Role:** canonical current roadmap for the public SSI V5 R&D, evidence and external-validation hub.  
**Project type:** independent / solo R&D programme.  
**Public boundary:** architecture, research protocols, training checkpoints, failures, repair records, benchmark plans, evidence and claim boundaries are public; proprietary implementation, credentials and reconstructive private runtime internals remain private.

## Current position

SSI V5 is currently operating as a persistent multi-agent research programme rather than a single benchmark or one training run.

The current public programme has six connected but separately evidenced tracks:

1. core SSI reliability and competence training;
2. CZARA multilingual Human–AI research collaboration;
3. Dynamic Mission V6 full-mission training;
4. WEB engineering training;
5. Mexico robotics / offline-resilience research;
6. external partner-defined benchmark and later replication work.

These tracks must not be collapsed into one score or presented as if planned work were already validated.

## Track F — external benchmark network

The long-term validation goal is not dependence on one laboratory or one professor.

The intended progression is:

```text
INTERNAL TRAINING
-> FROZEN INTERNAL VALIDATION
-> BLIND / HELD-OUT BENCHMARKS
-> PARTNER-DEFINED EXTERNAL R&D SESSION BENCHMARKS
-> SIMULATION / DIGITAL-TWIN VALIDATION
-> CONTROLLED PHYSICAL PILOTS
-> MULTI-PARTNER INDEPENDENT REPLICATION
```

A first low-risk industrial benchmark format is now being proposed externally:

```text
partner supplies a previously unseen bounded R&D problem
-> acceptance criteria frozen before the session
-> several human roles participate
-> CZARA preserves roles / requirements / decisions / revisions
-> DIRECTOR receives controlled context
-> no production-system write access required
-> PASS / FAIL / INCONCLUSIVE preserved
-> partner controls confidentiality / publication
```

External industrial outreach has begun, but **no company is described as a partner, validator or benchmark participant until it explicitly agrees**.

## External-validation maturity path

SSI should be interpreted through evidence maturity, not through one headline score:

```text
ARCHITECTURE / IMPLEMENTATION
-> INTERNAL TRAINING
-> FROZEN VALIDATION
-> BLIND / HELD-OUT TEST
-> EXTERNAL PARTNER-DEFINED BENCHMARK
-> INDEPENDENT REPLICATION
-> CONTROLLED PHYSICAL VALIDATION
-> DEPLOYMENT-SPECIFIC SAFETY / COMPLIANCE
```

A result at one level does not automatically establish the next level.
