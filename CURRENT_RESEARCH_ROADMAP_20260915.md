# SSI V5 — Current Research Roadmap — 2026-09-15

**Role:** canonical living roadmap for the current project sequence.  
**History rule:** earlier dated roadmaps remain preserved as historical state.

## Current position

SSI V5 currently has:

- preserved BODY_FROZEN and six ISKRA start-state lines;
- closed TEST 5 development validation;
- 7-BODY technical readiness evidence;
- verified BODY_FROZEN Foundation S1;
- DIRECTOR Foundation S1;
- Router V10 competence/recovery routing;
- Router S10 V1 / V3 / V2 comparison architecture;
- shared predeclared S1-S10 curriculum for matched comparison;
- implemented and locally validated Director Command Center pre-training gate;
- predeclared Tailscale cross-node consolidation architecture;
- implemented and measured drone/swarm software research domain;
- implemented and measured humanoid motion/stability software research domain;
- public 24-experiment cross-domain showcase: 12 drone + 12 humanoid;
- observer-only reviewer access separated from local owner/operator control.

## Current engineering sequence

The implementation order is now explicit:

```text
1. DIRECTOR + COMMAND CENTER
2. ROBERT
3. BODY_FROZEN 2.0 + ISKRA S1-S10 TRAINING
4. EVIDENCE / COMPARISON / S10 EVALUATION
5. CONTROLLED SYSTEM CONNECTION
6. TARGET-SPECIFIC VALIDATION
7. COMPETENCE CONSOLIDATION
```

DIRECTOR and Command Center are the current active engineering focus. ROBERT follows. BODY_FROZEN 2.0 and ISKRA lines are not treated as finished integrated systems before their training and evidence stages are complete.

## Workstream A — DIRECTOR + Command Center

Current goals:

- stabilize DIRECTOR runtime/state/CONTINUUM/Hermes integration;
- keep the owner/operator Command Center separate from lower-level diagnostics;
- preserve fixed integration slots and versioned data contracts;
- maintain truthful `OFFLINE`, `NOT_CONFIGURED` and `NOT_CONNECTED` states where applicable;
- preserve the rule that architecture readiness is not equivalent to completed integration.

## Workstream B — ROBERT

ROBERT is the next canonical engineering/execution line after the Director stage.

Goals:

- prepare and stabilize ROBERT independently;
- connect ROBERT through explicit versioned integration contracts;
- preserve ROBERT's own state/history;
- require regression/acceptance testing for imported competence rather than silent copying.

## Workstream C — BODY_FROZEN 2.0 + ISKRA S1-S10

The latest shared training-control protocol is:

```text
S1  Foundation
S2  LEGO + Micronetwork + Routing Practicum
S3  Applied Autonomy
S4  Robustness / Transfer Preparation
S5  Pre-Experiment Maturity Gate
S6  Multi-Path Equivalence
S7  Counterfactual Rerouting
S8  Cross-Domain Abstraction
S9  Novel Recombination
S10 Generalization Readiness Gate
```

S10 Variants V1, V3 and V2 are intended to receive matched exposure under the same curriculum and acceptance logic.

Critical boundary:

```text
OBSERVATION != COMPETENCE TRANSFER
```

Training lines may be observed without silently sharing newly learned competence before the declared consolidation gate.

## Workstream E — measured drone research domain

Current evidence includes:

- multiple simulated grids/groups;
- local-versus-collective experience;
- route adaptation and recovery;
- communication/localization degradation cases;
- task handoff and rerouting;
- flow-depth timing comparison;
- cross-grid consultation/consolidation;
- measured scoped consolidation effect;
- preserved negative regression evidence;
- external challenge entry.

Important measured scoped result:

```text
median post-consolidation speedup ~= 1.384x
median flow-cost reduction ~= 27.76%
competence-pool availability 6/5/5 -> 8/8/8
wind_corridor PASS -> FAIL regression preserved
```

The negative result is part of the evidence, not an error to hide.

## Workstream F — measured humanoid research domain

Current evidence includes:

- dedicated 3D humanoid interface;
- articulated-body/joint-chain state;
- obstacle, terrain and low-friction scenarios;
- instability/recovery loops;
- measured simulator-clock events;
- baseline/consolidated comparisons;
- `13/13` self-tests PASS;
- retained failure experience influencing a later slip-response path.

Physical humanoid equivalence is not claimed.

## Workstream G — controlled consolidation

Later competence movement follows:

```text
LOCAL EXPERIENCE
-> LOCAL EVIDENCE
-> DELTA PUBLICATION
-> TAILSCALE TRANSPORT
-> HERMES / IDENTITY UPDATE
-> S10 PRE-SELECTION
-> FAMILY GROUPING
-> DEEP COMPARISON WHERE REQUIRED
-> CHAMPION / CHALLENGER / SPECIALIST / HOLD
-> VERSIONED TARGET PLAN
-> TARGET-SPECIFIC RE-TEST
-> ACCEPT / HOLD / REJECT / ROLLBACK
-> EFFECT MEASUREMENT
-> ORGANIZATIONAL UPDATE
```

No competence is assumed safe to adopt merely because it helped another context.

## Workstream H — external validation

The strongest next credibility step is an unseen partner-defined challenge:

```text
EXTERNAL PROBLEM
-> CRITERIA FROZEN BEFORE RUN
-> EXECUTION
-> PASS / FAIL / INCONCLUSIVE PRESERVED
-> TIMINGS / EVIDENCE RECORDED
-> OPTIONAL TRANSFER / CONSOLIDATION
-> TARGET-SPECIFIC RE-VALIDATION
-> RESULT RETURNED TO PARTNER
-> PUBLICATION ONLY WITH APPROVAL
```
