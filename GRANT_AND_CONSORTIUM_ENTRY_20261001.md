## Longitudinal persistent-agent study

Beyond the active evidence-repair work, SSI now has a preregistered post-S40 study: [LONGITUDINAL_S40_WEB_AND_AFFECT_STUDY_20261004.md](LONGITUDINAL_S40_WEB_AND_AFFECT_STUDY_20261004.md). The planned experiment freezes BODY_FROZEN and ISKRA1..ISKRA6 at the S40 boundary, then compares how each actor acquires the same new WEB competence family.

Grant-relevant outputs are intended to include per-actor learning efficiency, REUSE/ADAPT/FULL_FLOW balance, new-skill formation, regressions, rollback/recovery, unseen transfer, memory/lifecycle changes and pre/post affect-like state proxies. This creates a controlled way to study how persistent agents diverge under training and whether evidence gates and frozen baselines detect undesirable change.

## One-minute project view

SSI V5 is a persistent multi-agent R&D programme built around:

- independent DIRECTOR and BODY_FROZEN cores;
- six ISKRA development/execution lines;
- versioned competence, checkpoints, rollback and provenance;
- evidence-preserving training and controlled consolidation;
- multilingual Human-AI research collaboration through CZARA;
- domain laboratories for drones, humanoids and rescue/multi-robot scenarios;
- an external-validation model where a partner defines an unseen bounded problem before execution.

The public repository is an evidence and collaboration hub. Reconstructive source code, credentials, private prompts, runtime internals and proprietary routing/micronetwork details remain private.

## What SSI can contribute to a consortium

SSI can contribute a bounded, evidence-oriented agentic-AI work package focused on:

- persistent multi-agent execution and competence reuse;
- continual/lifelong learning with explicit frozen evaluation;
- adaptive routing and controlled escalation;
- cross-agent and cross-domain consultation/consolidation;
- rollback, recovery and failure-aware execution;
- multilingual Human-AI research collaboration;
- benchmark design, evidence capture and falsification;
- simulation/digital-twin experimentation;
- later integration with partner-owned robotics or autonomous-system infrastructure.

SSI does not require a consortium to accept broad capability claims. The preferred model is measurable:

```text
PARTNER DEFINES UNSEEN BOUNDED PROBLEM
-> ACCEPTANCE CRITERIA FROZEN
-> SSI VERSION / TARGET DECLARED
-> RUN
-> PASS / FAIL / INCONCLUSIVE PRESERVED
-> EVIDENCE RETAINED
-> OPTIONAL CONSOLIDATION
-> TARGET-SPECIFIC RE-VALIDATION
```

## What SSI needs from a consortium

Depending on the target call, the most useful partner capabilities are:

1. **AI / continual-learning research partner** — methodology, baselines and independent scientific review.
2. **Robotics / drone / multi-robot laboratory** — simulation and controlled physical validation.
3. **Humanoid / manipulation / stability laboratory** — target-specific validation where relevant.
4. **Rescue / civil-protection domain partner** — operational scenarios, constraints and expert acceptance criteria.
5. **Cybersecurity / safety / ethics partner** — threat modelling, safety cases, data/governance review.
6. **Industrial end user / integrator** — real use case, integration boundary and exploitation path.
7. **Independent benchmark / replication partner** — unseen tasks and reproducibility testing.

No organization is described as a consortium member, validator or endorser until it explicitly agrees.

## Proposal planning position

The current repository is strong enough to support partner discussions and proposal preparation, but it is not itself a complete grant proposal.

Before submission to a specific call, the consortium must freeze:

- target topic and expected outcomes;
- legal beneficiaries / associated partners;
- starting and target TRL per technical asset;
- work-package ownership and person-months;
- deliverables and milestones;
- total budget and cost categories;
- data-management plan;
- ethics / safety / cybersecurity obligations;
- background IP and access rights;
- exploitation and dissemination plan;
- external validation sites and acceptance criteria.
