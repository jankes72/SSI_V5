# SSI V5 — Drone-domain R&D collaboration status

**Date:** 2026-09-14
**Status:** IMPLEMENTED SOFTWARE RESEARCH DEMONSTRATOR

SSI V5 now includes a working software-level research demonstrator for a drone/swarm domain. This moves the drone branch from a purely prospective roadmap item to an implemented domain-transfer artifact.

The demonstrator contains a private local collaboration interface for the project author and explicitly authorized research partners, plus a separate observer-only review surface for reviewers, investors and grant evaluators. The local interface is intended for joint experimentation and configuration. The public/reviewer surface follows the existing SSI rule `OBSERVE != CONTROL`.

The laboratory supports multiple simulated groups, configurable units, domain scenarios, V1/V2/V3 comparison hooks, per-flow timing, evidence capture, custom externally supplied challenge definitions and before/after comparison around consolidation experiments.

A core purpose of this branch is to make later collaboration possible without changing the main SSI roadmap. An independent expert, laboratory or company can define a real domain problem and acceptance criteria, then use the laboratory as a controlled environment for a jointly agreed research challenge.

The current artifact demonstrates transfer of SSI research methodology, state/evidence structure and interface concepts into a second domain at the software-laboratory level. It does not claim certified physical operation, production readiness, external replication or complete binding of the private SSI/V10/S10 runtime to real hardware.

The next credibility step is external domain review and partner-defined challenge testing under frozen acceptance criteria.
