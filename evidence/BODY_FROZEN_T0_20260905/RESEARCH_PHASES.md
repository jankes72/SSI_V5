# Research phases after BODY_FROZEN T0

This file records the comparison protocol at a high level. It does not claim that future stages have already been completed.

## T0 — frozen starting point

Preserve one stable pre-ISKRA baseline: runtime state, CONTINUUM closure, micronetwork/V10 baseline, lifecycle counters and test evidence.

## T1 — no-ISKRA comparison line

The frozen baseline is intended to execute the same controlled experiment contract before ISKRA is introduced. Measurements should include time, iteration count, failures, test results, produced artifacts, new validated competences and resource cost where measurable.

## T1-ISKRA — independent variants

Each ISKRA variant should start from the same T0 and receive the same experiment contract and comparable resource limits. Differences should emerge after the shared start, not from different initial bodies.

## T2 — consolidation

A later, separately tested mechanism may compare validated competences produced by the independent lines. Equivalent solutions should increase evidence/coverage rather than silently create duplicate skills. A challenger should replace a champion only under an explicit benchmark contract; ambiguous results should request more cases rather than force promotion.

No T1 or T2 performance result is claimed in the T0 evidence package.
