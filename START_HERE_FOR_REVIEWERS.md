## What changed by 2026-09-14

### Training control now extends to S1–S10

The older S1–S5 V2 suite remains valid historical predeclaration evidence. The latest comparison-control methodology is the shared S1–S10 curriculum for S10 V1 and V2.

```text
S1 Foundation
S2 LEGO + Micronetwork + Routing Practicum
S3 Applied Autonomy
S4 Robustness / Transfer Preparation
S5 Pre-Experiment Maturity Gate
S6 Multi-Path Equivalence
S7 Counterfactual Rerouting
S8 Cross-Domain Abstraction
S9 Novel Recombination
S10 Generalization Readiness Gate
```

This is **predeclared methodology**, not a claim that every line has completed all ten stages.

### Router S10 now has explicit V1/V2 comparison lines

```text
V1 = lean reference/control variant
V2 = richer optimized control/observability variant
```

Published V2 evidence includes scoped local reuse/recomputation and timing results. V1 remains a separate control/reference line. No universal V2 superiority is claimed.

See [`S10_VARIANTS_START_HERE_20260913.md`](S10_VARIANTS_START_HERE_20260913.md).

### Drones and humanoid are implemented software domains

Drones and humanoid robotics are no longer only planned software targets.

**DRONES / SWARM** now has a software research laboratory with multiple grids/groups, local-versus-collective experience, routing/recovery scenarios, before/after comparison, timing/evidence paths and cross-grid consultation/consolidation capability.

**HUMANOID MOTION / STABILITY** now has a dedicated 3D software research laboratory with articulated-body state, obstacle/terrain/slip scenarios, instability/recovery loops and before/after learning comparison.

## Critical scientific boundary

```text
DOMAIN LAB EXISTS != EXPERIMENT PASSED
SOFTWARE TRANSFER != PHYSICAL VALIDATION
CONSULTATION / CONSOLIDATION OPTION != BENEFIT PROVEN
```

The original 21-experiment programme remains scientifically separate:

```text
7 BODY lines x 3 experiments = 21
A = DRONES
B = HUMANOID
C = NEW DOMAIN independently selected by that SSI line
```

The software laboratories improve readiness for these experiments; they do not make the complete 21-outcome set a finished result.

## Why this is relevant to external reviewers

SSI V5 can now be reviewed at several distinct levels:

- historical engineering evidence and regressions;
- persistent competence and Router V10 behavior;
- S10 V1/V2 controlled comparison design;
- predeclared S1–S10 training methodology;
- implemented drone/swarm domain-transfer infrastructure;
- implemented humanoid motion/stability domain-transfer infrastructure;
- future externally supplied challenge cases;
- later physical and independent validation.

## Reviewer access boundary

```text
PUBLIC REVIEWER
= sanitized status / evidence / allowed questions
!= ROOT
!= arbitrary mission execution
!= runtime configuration write access
```

The reviewer interface is deliberately observer-only.

## What reviewers should not infer

SSI V5 does not currently claim:

- completed S1–S10 training across all lines;
- successful completion of all 21 cross-domain experiments;
- complete seven-line S10 scientific validation;
- universal V10/S10 superiority;
- physical drone or humanoid validation;
- independent external replication;
- production readiness;
- AGI or consciousness.
