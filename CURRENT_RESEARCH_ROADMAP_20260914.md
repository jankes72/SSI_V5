## Workstream B — Router S10 controlled comparison

Three S10 lines are now maintained rather than silently replacing one configuration with another:

```text
V1 = lean reference/control configuration
V3 = intermediate MetaNetwork configuration
V2 = richer optimized control/observability configuration
```

The numeric order is lineage, not ranking. V3 is the third explicit research line and tests an intermediate architectural trade-off while preserving its own MetaNetwork design.

The comparison target is broader than speed. It includes semantic equivalence, family assignment, Champion/Challenger decisions, false merge/split behavior, wrong promotions, recomputation/reuse amount, regression, recovery and fail-closed integrity behavior.

Current published engineering evidence remains scoped. V3 is under synchronization/validation and does not yet have a final performance closure record. Full scientific seven-line success is not claimed.

## Cross-domain scientific boundary

The domain laboratories now exist, but the predeclared 21-experiment scientific program remains a separate layer:

```text
7 BODY lines x 3 experiments = 21
A = DRONES
B = HUMANOID
C = NEW DOMAIN selected independently by that SSI line
```

Therefore:

```text
DOMAIN IMPLEMENTED != EXPERIMENT PASSED
DOMAIN INTERFACE EXISTS != PHYSICAL VALIDATION
CONSULTATION / CONSOLIDATION OPTION EXISTS != BENEFIT PROVEN
COMMAND CENTER IMPLEMENTED != ALL FUTURE INTEGRATIONS LIVE
```

The software laboratories reduce implementation risk and create a concrete environment for later controlled testing, external challenge design and evidence capture.

## Held-out mechanism tests

Seven Micronetwork + Router V10 mechanism-test packages remain predeclared and not yet claimed executed.

Their purpose is to stress reuse, verification/adaptation, false-reuse protection, anti-loop behavior, alternative routing, recovery and persistence before interpreting stronger cross-domain claims.

## Post-training / post-experiment consolidation

The later research question remains whether competence learned independently can be consolidated without destroying provenance or introducing harmful false reuse.

Conceptual sequence:

```text
independent BODY histories
-> frozen evidence
-> S10 functional comparison
-> Champion / Challenger / Specialist / Hold decisions
-> versioned descendant
-> regression
-> later transfer challenge
```

The Command Center already reserves a visible organizational path for such provenance-preserving competence movement, but it does not make promotion automatic.

No positive outcome is assumed in advance.

## External validation path

The intended credibility ladder is now:

```text
internal engineering evidence
-> implemented software domain labs
-> frozen external challenge definitions
-> independent/domain-expert review
-> matched controlled comparisons
-> physical validation where safe and resourced
-> independent replication where feasible
```

External reviewers may define challenge cases and acceptance criteria, but public reviewer access remains observer-only and does not provide ROOT authority.
